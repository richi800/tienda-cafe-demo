# Recursos de marca

Esta carpeta contiene el logo de Café Ladera.

- Archivo esperado: `logo.svg`, proporcionado por el dueño del proyecto. No se debe crear ni
  modificar un logo sustituto.
- Mientras `logo.svg` no exista, la interfaz muestra el nombre "Café Ladera" en texto.
- Los archivos de esta carpeta se sirven desde la raíz del sitio, por ejemplo `/brand/logo.svg`.
